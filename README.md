# Dovetail

Dovetail is a customer intelligence platform that aggregates customer feedback from sales calls, support tickets, user-research sessions and surveys, then uses AI to transcribe, analyze, tag and structure it into a searchable research repository. Teams across product, design, research, customer experience, sales and marketing turn that signal into insights, docs, dashboards and automated agents.

The Dovetail Public API (base `https://dovetail.com/api/v1`) exposes projects, folders, docs, insights, data (notes), highlights, tags, themes, channels, topics, contacts, users, custom fields, files, comments and transcripts, plus Magic Search, Search V2 and Magic Summarize. Auth is Bearer API token; cursor-based pagination; 200 requests/minute per workspace. Dovetail also ships an official hosted MCP server at `https://dovetail.com/api/mcp`.
